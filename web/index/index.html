The first index is on its way

We are scanning the servers in the official MCP registry and will tell maintainers before any grade goes public. Until then, you can grade any server yourself with the same tool that will build this index.

Install with Go 1.26 or later, then scan: go install github.com/greyquill/mcpsight/cmd/mcpsight@latest mcpsight scan https://your-server.example/mcp

Source, docs, and the scoring rubric are on GitHub.
