Self-host

Run the registry index

mcpsight-index runs the same analyzers over a whole registry and publishes the results as a static site. Any grade it shows, you can reproduce with the CLI.

The public index is not published yet.

Maintainers will hear from us before any grade goes public. Until then you can run your own.

Preview the site

make preview     # no database, opens your browser

Run it with Docker

Postgres and the service together:

docker compose -f deploy/docker-compose.yml up --build     # http://localhost:8080

A Helm chart is in deploy/helm. Postgres can be any Postgres: a container, RDS, or Cloud SQL.

Populate and publish

mcpsight-index migrate
mcpsight-index scan-batch --seed testdata/index-seed.json
mcpsight-index snapshot -o web/data/snapshot.json

The site reads web/data/snapshot.json. Until one exists, it shows a "coming soon" page.

Commands

CommandWhat it does
migrateCreate or update the database schema
crawlList servers from the official registry or a seed file
scan-batchScan the servers and store the results
snapshotWrite the JSON the static site reads
serveRun the JSON API and serve the site
previewServe the static site with no database

Configuration

Environment variables only:

VariableDefaultMeaning
MCPSIGHT_DSNPostgres connection string. DATABASE_URL works too
MCPSIGHT_ADDR:8080Listen address
MCPSIGHT_WEBwebFolder holding the static site
Local servers need the sandbox.

The service image is minimal and scans remote servers only. Run scan-batch on a Linux host with bubblewrap, pointed at the same database.
